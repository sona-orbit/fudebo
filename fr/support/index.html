Aide

Voici comment utiliser Fudebo et les réponses aux questions fréquentes. Si vous rencontrez un problème dans l’app, le moyen le plus rapide de nous prévenir est de toucher « Signaler un problème » dans les réglages. La version de l’app et le modèle de l’appareil sont ajoutés automatiquement.

Ou envoyez un e-mail :sona.orbit.hi@gmail.com

Comment se compose une page quotidienne

  • Une page contient environ 10 caractères. Ceux à réviser viennent en premier ; les nouveaux remplissent les places restantes.
  • Dans les réglages, vous choisissez 2, 3 ou 5 nouveaux caractères par jour.
  • Les rangées de kana s’ouvrent l’une après l’autre. Quand vous retenez toute une rangée, la suivante s’ouvre.
  • La version gratuite propose une page par jour. Avec Pro, vous pouvez continuer à écrire après la page du jour ou choisir une rangée à travailler.

Pendant l’écriture

  • Écrivez avec votre doigt et soulevez-le après chaque trait.
  • Si vous vous trompez sur un trait, touchez « Annuler le trait ».
  • Si vous ne vous souvenez plus du caractère, touchez « Indice d'un trait » ou « Voir la réponse ».
  • Pour réécouter la lecture, touchez « Réécouter ».

Si un trait est incorrect

Le trait incorrect devient rouge et le tracé dans le bon ordre s’affiche. Vous repassez une fois sur le caractère, puis vous l’écrivez de nouveau sans modèle. Ce caractère revient le lendemain.

Couleurs du tableau des kana

Sur l’écran d’accueil, plus une case est foncée, mieux vous connaissez ce caractère. Touchez un caractère pour voir l’ordre de ses traits.

Pro

  • Abonnement mensuel, annuel ou achat définitif. Les abonnements se renouvellent automatiquement et peuvent être résiliés à tout moment ; l’achat définitif se fait en une seule fois.
  • Sur un nouveau téléphone ou après une réinstallation, touchez « Restaurer les achats » dans les réglages.
  • Pour gérer ou résilier un abonnement, touchez « Gérer l'abonnement’abonnement » dans les réglages de l’app, ou ouvrez Réglages de l’iPhone → votre nom → Abonnements.

Rappel quotidien

Activez le rappel quotidien et choisissez une heure dans les réglages. Si vous ne recevez pas les rappels, vérifiez que les notifications de Fudebo sont activées dans Réglages de l’iPhone → Notifications.

Effacer votre historique

« Recommencer (effacer la progression)’historique) », dans les réglages, supprime les caractères que vous avez écrits et vos tampons quotidiens. Cette action est irréversible.
