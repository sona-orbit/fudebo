# Fudebo (筆寶)

Website for **Fudebo**, an iPhone app for practising Japanese kana handwriting. You see the reading,
write the character from memory with your finger, and the app checks stroke count, order, direction and shape.
One page a day, about 10 characters.

Served by GitHub Pages at https://sona-orbit.github.io/fudebo/

- Home, privacy and support pages in nine languages: English, 繁體中文, 简体中文, 日本語, 한국어, Español, Deutsch, Français, Português (Brasil)
- Static HTML and CSS, no build step on this repository
- The writing grid on the home page uses stroke data from [KanjiVG](https://kanjivg.tagaini.net/) by Ulrich Apel,
  licensed under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)
- Published by Sona Orbit. To report a problem, use "Report a problem" in the app's Settings.
